故障演练步骤

本地 Compose 环境
  • 确认容器名docker ps --filter name=ops-lab-backend
  • 停止 backend-adocker stop ops-lab-backend-a-1
  • 触发失败计数在页面连续点「10 次连发」三次，让 Nginx 记满 max_fails=3。
  • 观察恢复docker start ops-lab-backend-a-1，等 fail_timeout=10s 后继续压测。
  • 查看 Nginx 日志docker logs --tail 100 ops-lab-nginx-1
  • 查看后端页面docker exec ops-lab-backend-a-1 ls /usr/share/nginx/html
