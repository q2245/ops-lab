# Kubernetes

## 创建集群

```bash
brew install kind
make k8s
```

这会创建一个 1 control-plane + 2 worker 的集群，并部署三副本的演示应用。

## 核心概念

| 对象 | 作用 |
|------|------|
| Pod | 最小调度单位 |
| Deployment | 声明式管理副本，滚动更新、回滚 |
| Service | 稳定的虚拟 IP 和 DNS |
| ConfigMap / Secret | 配置和敏感数据 |
| Namespace | 资源隔离 |
| HPA | 自动扩缩容 |
| NetworkPolicy | 网络访问控制 |

## 排障顺序

1. `kubectl get pods` 看状态
2. `kubectl describe pod <pod>` 看 Events
3. `kubectl logs <pod> --previous` 看上一次崩溃前的日志
4. `kubectl get events -A --sort-by='.lastTimestamp'`
5. `kubectl top pod` 看资源
