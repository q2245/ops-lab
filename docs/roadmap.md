# 运维学习路线图

## 阶段一：Linux 与网络（1-2 周）

目标：能独立登录一台 Linux 服务器，排查常见问题。

练习环境：`make up PROFILE=linux`

## 阶段二：可观测性（2 周）

目标：能搭建并读懂监控系统，能定位一次线上抖动。

练习环境：`make up PROFILE=core`

## 阶段三：中间件（2-3 周）

目标：至少深入掌握一门，理解原理并能调优。

练习环境：`make up PROFILE=redis`、`db`、`mq`

## 阶段四：容器与 K8s（3 周）

目标：能部署、排障、调优 K8s 上的应用。

练习环境：`make k8s`

## 阶段五：CI/CD 与自动化（1-2 周）

目标：能把部署过程自动化。

练习环境：`make up PROFILE=cicd`

## 阶段六：SRE 方法论（持续）

目标：从「会运维」到「懂可靠性」。

- SLI/SLO/Error Budget
- 容量规划
- 故障复盘
- 混沌工程

## 一条主线

学运维不要按工具学，按「问题」学。遇到「服务为什么慢」，你会自然而然地把 Linux、网络、应用、中间件、数据库、监控全串起来。这套 lab 的价值就是给你一个能反复制造问题、又能看到全链路数据的环境。
